Buffalo Music Calendar Design Doc

Problem I’m Solving: I really like going to see live music events. However, it is a pain in the ass to sort through the many different platforms and company pages to find events. For example, I frequently check the Caz’s website or instagram page for upcoming shows, as well as Electric City’s website and Ironworks website. I am not on Facebook, but many music events are advertised there as well. I want to have a digital view of all upcoming concerts/music events for the next X amount of days.

End Goal: A website with a single web page that displays a calendar with music events. A user can toggle between a weekend, 7, 14, or 30 day view. An AI agent scrapes a number of sources every morning and updates the events via Github pull request. Each day in the interactive calendar has a number of events. Each event has its own box that displays the band name, venue location, time, and price if possible. Clicking on the box brings you to the event specific page, which should mirror the content from the source (facebook post, instagram post, website, etc.) 

Phase 1: Let’s start with a webpage that shows concerts for only this upcoming weekend. It displays the dates, and then three boxes that list shows. The boxes represent Friday, Saturday, and Sunday. Use a cool, modern font. Lets use a dark purple and blue color theme, with neutral accent colors. Use modern web design approaches for the calendar. We can create a dummy directory for the sources and load in generated ones. We will use Phase 2 to implement that agent workflow and updating. Leverage modern frontend tech stack approaches.
